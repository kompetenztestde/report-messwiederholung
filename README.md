# TBA3 Rückmeldung für Messwiederholungen

Developed by netzkolchose.de UG (haftungsbeschränkt)

This is the prototype of a website showing the results of student evaluations of reading abilities and their development over 3 tests in 2nd and 3rd grade.
One or more test results can be displayed in one informative graphical screen and  
learning material that matches the individual performances can be assigned to the students.

## Technische Dokumentation

### Accessibility

Because of its graphical nature, the results view is not made accessible. Also most accessibility features are not
implemented in this prototype.

### Local development

The server is implemented with the [Django](https://www.djangoproject.com/) library. It merely serves static files
and stores test results in the database. 

The frontend is implemented in TypeScript using the [Vue](https://vuejs.org/) library in Composition mode.

#### Run frontend

Install node packages

```shell
npm install
```

Compile and Hot-Reload, places files into `backend/static/`, served by Django.

```shell
npm run dev
```

Type-Check, Compile and Minify for Production

```shell
npm run build
```

#### Run backend

```shell
cd backend

poetry shell
poetry install

./manage.py migrate     # create initial database
./manage.py runserver
```

Then visit http://localhost:8000 - the website is served there locally


### Importing "internal" data

Data in the "internal format" can be imported to the database via:

```shell
./manage.py tba_import_internal_data import [filename.json] [name]
```

The file must be json formatted, `name` is just an internal identifier for the imported data.
Calling this returns a code which can be used in the frontend to load the data, e.g.:

http://localhost:8000/?code=lUaTW6DMaRZxoyGoQFJ8tXYZ20X5lCCG3hC3eQkK-Ug

The codes of all imported results can be shown via

```shell
./manage.py tba_import_internal_data list
```

Data can be deleted via

```shell
./manage.py tba_import_internal_data delete [name or code]
```

### Importing TBA3 data

The converter from TBA3 to "internal format" is in [api/conversion.py](backend/api/conversion.py).

The internal format contains one or several tests and the summed correct/wrong values for each student.
One list of TBA3 students items (see [demo data](https://apps.indibit.eu/tba3-api/groups/3b-deutsch/items?type=students))
contains single task results from one test. 

The `TBA3Converter` class allows adding one or more students lists and accumulates them into the internal format. 
Please see the source code in [api/conversion.py](backend/api/conversion.py) and 
[commands/tba_import_data.py](backend/tba3_nk/management/commands/tba_import_data.py) 
to see how the conversion is accomplished. 

Since we do not have real data in TBA3 format right now, this is only for demonstration purposes. The following
command reads a list of TBA3 students items, converts them into the internal format and prints the result 
to the console:

```shell
./manage.py tba_import_data import [filename.json]
```

You can get the TBA3 demo data to test conversion with:

```shell
curl https://apps.indibit.eu/tba3-api/groups/3b-deutsch/items?type=students > students-data.json
```

### Project structure

```
.
├── backend/                # django backend
│   ├── tba3_nk/
│   │   ├── migrations          # generated by django from models.py
│   │   ├── models.py           # django database structure declaration (for saved test results)
│   │   └── settings.py         # backend django settings
│   ├── manage.py               # Django CLI tool, most relevant for local development: runserver
├── src/                    # vue frontend
│    ├── assets                 # images, videos, pdfs, fonts
│    ├── components             # reusable components
│    ├── router
│    │   └── index.ts           # routes are declared here
│    ├── types                  # typescript type declarations
│    ├── views                  # website pages and single use components
│    └── quasar-variables.sass  # main design variables
└── package.json                # npm frontend package list
```

### External assets

The application uses external assets, such as PDF files, videos and audio files, that are not part of the repository.
The assets are hosted under the base URL <https://files.ktest.de/tba3/>. To serve the assets from another server, the
environment variable `VITE_ASSET_BASEURL` can be set to the base URL of the server hosting the assets during build time.
